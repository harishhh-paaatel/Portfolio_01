I'm an undergraduate at Maharaja Institute of Technology, Mysore, studying Computer Science and Engineering (September 2023 to August 2027, expected). My work sits where backend software meets machine learning: FastAPI services with defined JSON contracts, ML pipelines, computer vision tools and LLM-based applications.

Backend engineering, computer vision and Edge AI feel like one skill set to me. A detector is only useful if it is evaluated honestly and can run within its latency and memory limits, and a model behind an API needs the same testing, logging and debugging discipline as any other service.

When I build something, I try to compare it against a baseline, look at where it fails (per-class errors, false positives), and measure the cost of running it. I'm currently interning in Edge AI and machine vision, and I'm looking for software engineering internships where I can keep learning on real systems.

Selected projects

Things I've built

GraphRAG Knowledge System

Plain chunk-based RAG loses the relationships between facts spread across documents. This project tests whether a knowledge graph retrieves better.

  • Extracts entities and relationships from unstructured documents and builds a knowledge graph with NetworkX.
  • Serves retrieval and question answering through a FastAPI REST service with defined JSON contracts.
  • Compared against a chunk-based RAG baseline.
  • Packaged with Docker so it can be reproduced.
  • Python
  • FastAPI
  • LLMs
  • NetworkX
  • Docker

PCB Defect Detection & Edge AI

Internship work at ProEmbSys Technologies

Inspecting boards by eye is slow and inconsistent. The goal was a detector for four defect classes that can also run on edge hardware.

  • Python/OpenCV tool detecting shorts, open traces, missing solder and misalignment.
  • Transfer learning with YOLOv8 and MobileNet-SSD, evaluated with precision, recall and mAP@0.5.
  • Per-class root-cause analysis of false positives.
  • Edge inference profiled for latency, FPS, SRAM/Flash usage and energy consumption (TensorFlow Lite).
  • Python
  • OpenCV
  • YOLOv8
  • MobileNet-SSD
  • TensorFlow Lite

Drone Navigation & 3D Reconstruction

2nd prize, Innovotsava 2026 Drone Fair

A simulated drone flies a scene, captures images with known camera poses, and those images are turned back into a 3D model.

  • Controller-based drone navigation in AirSim on Unreal Engine.
  • Automated image capture alongside camera-pose information.
  • 3D scene reconstruction with Structure from Motion.
  • Python
  • AirSim
  • Unreal Engine
  • OpenCV
  • NumPy
