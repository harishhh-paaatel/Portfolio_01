[ 04 ] Selected / Work

Selected projects.

Four projects across GraphRAG, computer vision, edge AI and full-stack engineering — each one built as a working system, not just an experiment.

  1. 01

    GraphRAG Knowledge System

    An LLM-powered knowledge retrieval system that combines knowledge graphs with retrieval-augmented generation.

    Built a pipeline that extracts entities and relationships from unstructured documents, constructs a NetworkX knowledge graph, and uses graph-based retrieval to answer questions through an LLM. The system was benchmarked against a traditional chunk-based RAG baseline to compare retrieval quality, exposed through a FastAPI REST service and containerized with Docker for reproducibility.

    • Python
    • LLMs
    • GraphRAG
    • NetworkX
    • FastAPI
    • Docker
    2026
  2. 02

    PCB Defect Detection & Edge AI

    Computer vision system for detecting manufacturing defects on PCBs using deep learning.

    At ProEmbSys, I translated PCB inspection requirements into an object-detection problem and worked with YOLOv8 and MobileNet-SSD to detect four defect categories. I also worked on real-time Python/OpenCV pipelines and optimized edge inference while monitoring latency, FPS, SRAM/Flash usage and energy consumption.

    • Short circuits
    • Open traces
    • Missing solder
    • Misalignment
    • Python
    • YOLOv8
    • MobileNet-SSD
    • OpenCV
    • TensorFlow Lite
    • Edge AI
    2026 Industry project
  3. 03

    Drone Navigation & 3D Reconstruction

    Controller-based drone simulation with automated image capture and 3D scene reconstruction.

    Built a drone navigation simulation using AirSim and Unreal Engine, generated flight-path data, and created a Python/OpenCV/NumPy pipeline that captured RGB images together with camera-pose information. The captured sequences were then used for Structure from Motion-based 3D reconstruction.

    • Python
    • AirSim
    • Unreal Engine
    • OpenCV
    • NumPy
    • Structure from Motion
    2026 2nd Prize — Innovotsava 2026 Drone Fair
  4. 04

    Full-stack library management platform with authentication, automation and analytics.

    Built a full-stack system with FastAPI REST APIs, a JavaScript UI and SQLAlchemy, covering books, users, loans and reservations.
